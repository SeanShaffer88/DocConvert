# DocConvert

Planned document-conversion library with a C ABI.

**Status: planned; no implementation published.** There is no converter source, C header, build guide, or release binary available here yet. Markdown, HTML, CSV, JSON, and plain-text support are proposed scope, not verified capabilities.

The first milestone is one bounded conversion path with documented input/output rules, error handling, a real consumer example, and tests. File-format compatibility and Windows/CPU support remain unverified.
